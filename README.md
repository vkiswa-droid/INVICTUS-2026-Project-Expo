# INVICTUS 2026 — Project Expo Pro

Professional dark futuristic registration website inspired by the supplied reference design.

## Run on Windows
Open PowerShell in this folder:

npm install
npm start

Then open:
http://localhost:3000

Admin:
http://localhost:3000/admin/login

Default admin:
gojo / jigokuraku@2008

Registrations are saved in `data/registrations.json`.

No better-sqlite3, node-gyp, Python or Visual Studio is required.
